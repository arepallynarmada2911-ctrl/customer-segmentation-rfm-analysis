# Customer Segmentation Using RFM Analysis

## Project Overview
This project focuses on segmenting customers based on their purchasing behaviour using **RFM (Recency, Frequency, Monetary) Analysis**. It helps businesses understand customer value, identify loyal customers, and develop targeted marketing strategies.

## Objectives
- Analyze customer purchasing behaviour.
- Calculate Recency, Frequency, and Monetary scores.
- Identify different customer segments.
- Visualize customer insights using Power BI.
- Support data-driven marketing and retention strategies.

## Tools & Technologies
- **Python:** Pandas, NumPy, Matplotlib, Seaborn
- **Power BI:** Data visualization and interactive dashboard
- **Jupyter Notebook:** Data analysis
- **Excel/CSV:** Dataset handling

## Project Workflow
1. Data loading and exploration.
2. Data cleaning and preprocessing.
3. RFM metric calculation.
4. Customer scoring and segmentation.
5. Exporting customer segment results.
6. Building an interactive Power BI dashboard.

## RFM Methodology

| Metric | Meaning |
|---|---|
| Recency | How recently a customer purchased |
| Frequency | How often a customer purchased |
| Monetary | How much a customer spent |

## Repository Contents
- `Customer_Segmentation_using_RFM_Analysis.ipynb` – Python analysis
- `Customer Segmentation using RFM Analysis.pbix` – Power BI dashboard
- `OnlineRetail.csv.zip` – Dataset
- `customer_segments (1).csv` – Segmentation output

## Business Applications
- Identify high-value and loyal customers.
- Improve customer retention.
- Design targeted marketing campaigns.
- Identify customers who need re-engagement.
- Support customer-focused business decisions.
